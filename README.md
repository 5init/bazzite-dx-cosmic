# bazzite-dx-cosmic

This is Bazzite DX with COSMIC DE based on bazzite-dx-gnome image from Universal Blue

# Switch to This Image

From your bootc system, run the following command.
```bash
sudo bootc switch ghcr.io/5init/bazzite-dx-cosmic
```
This should queue your image for the next reboot, which you can do immediately after the command finishes.
